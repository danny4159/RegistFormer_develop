================================================================================
0. PatchNCE가 무엇을 위한 loss인가 (직관)
================================================================================

  목적: 합성 결과 fake_b 가 입력 real_a(T1)와 **구조(내용)** 를 유지하도록 강제.

  문제 상황
    - GAN loss는 "T2처럼 보이게" 만들지만 구조가 틀어져도 막지 못함.
    - Contextual/style loss는 참조 T2의 텍스처·대비를 입히는 역할.
    - 그러면 "T1의 해부학적 구조"가 보존된다는 보장이 약함.

  PatchNCE의 아이디어 (CUT, Park et al. 2020 에서 유래)
    - real_a 의 어떤 위치 패치와, fake_b 의 **같은 위치** 패치는
      서로 대응(positive)해야 한다.
    - real_a 의 그 위치 패치와, fake_b 의 **다른 위치** 패치들은
      구별(negative)되어야 한다.
    - 즉 "같은 자리끼리는 가깝게, 다른 자리와는 멀게" → 대조학습(contrastive).
    - 이렇게 하면 픽셀값을 직접 비교(L1)하지 않으면서도
      위치별 구조 대응이 유지됨 → cross-modality(T1→T2)에 적합.

  중요한 특징
    - "특징(feature)"을 뽑는 인코더로 **별도 VGG가 아니라 Generator 자기 자신**을
      사용 (nce_on_vgg=False 경로). encode_only 모드로 중간 feature를 추출.
    - 그래서 T1과 fake_b를 같은 Generator 인코더에 통과시켜 feature 공간에서 비교.

4. InfoNCE 계산 — PatchNCELoss
================================================================================
  파일: patch_nce_loss.py:15-57
  설정: nce_T=0.07, batch_size=1,
        nce_includes_all_negatives_from_minibatch=False

  한 레이어에 대해 criterionNCE(feat_q, feat_k) 호출.
    feat_q = feat_a_pool[layer]   [256, 256]   (query = real/T1 쪽)
    feat_k = feat_b_pool[layer]   [256, 256]   (key   = fake 쪽)
  (proposed_synthesis_module.py:399-401 에서 criterionNCE(f_a, f_b))

  num_patches = 256 (=P),  dim = 256 (=nc)
  feat_k = feat_k.detach()     ★ key 쪽은 gradient 차단 (q만 학습 신호 받음)

  4-1. Positive logit (같은 위치끼리)   line 21-23
  --------------------------------------------------------------------------------
      l_pos = bmm( feat_q.view(256, 1, 256),        # [256, 1, 256]
                   feat_k.view(256, 256, 1) )       # [256, 256, 1]
            = 각 패치 i에 대해  q_i · k_i  (자기 자신과의 내적)
      l_pos: [256, 1]
      → i번째 real 패치와 i번째 fake 패치(같은 위치)의 코사인 유사도.

  4-2. Negative logit (다른 위치들과)   line 34-50
  --------------------------------------------------------------------------------
      batch_dim_for_bmm = batch_size = 1
      feat_q = feat_q.view(1, 256, 256)    # [1, P, dim]
      feat_k = feat_k.view(1, 256, 256)
      npatches = 256

      l_neg_curbatch = bmm(feat_q, feat_k.transpose(2,1))   # [1, 256, 256]
        → (i,j) 성분 = q_i · k_j  (모든 위치쌍의 유사도 행렬)

      # 대각선(i==j)은 positive와 중복이므로 제거:
      diagonal = eye(256)[None]                 # [1,256,256] bool
      l_neg_curbatch.masked_fill_(diagonal, -10.0)   # 대각선을 exp(-10)≈0 으로
      l_neg = l_neg_curbatch.view(-1, 256)      # [256, 256]

      → 각 패치 i의 negative = 자기 외 나머지 255개 위치 (+마스킹된 자기자리 1개).

    ★ negative가 "다른 이미지"가 아니라 **같은 이미지 안의 다른 위치**.
      batch_size=1, all_negatives_from_minibatch=False 이므로
      한 이미지 내부 256개 패치가 서로의 negative가 됨.

  4-3. InfoNCE = temperature scaling + CrossEntropy   line 52-55
  --------------------------------------------------------------------------------
      out = cat(l_pos, l_neg) / nce_T           # [256, 1+256] = [256, 257]
        열 0    = positive logit
        열 1~256 = negative logits (열 (i+1)은 마스킹되어 -10/0.07 ≈ -143)
      nce_T=0.07 로 나눔 → 유사도 차이를 sharpening (작을수록 대조 강함)

      target = zeros(256)  (정답 클래스는 항상 0번 = positive)
      loss = CrossEntropy(out, target)          reduction='none' → [256]

      의미: 각 패치에 대해 "positive가 257개 후보 중 0번" 이 되도록
            softmax 분류 문제를 푸는 것.
            → q_i·k_i (같은 위치)가 q_i·k_j (다른 위치)들보다 커지도록 학습.

      반환: [256] (패치별 loss)

================================================================================
C0. Contextual loss가 무엇을 위한 loss인가 (직관)
================================================================================

  목적: fake_b 가 참조 T2 의 **텍스처·대비(=modality 스타일)** 를 갖게 만들되,
        픽셀이 정확히 정렬돼 있지 않아도(=misalign) 되게.

  왜 L1/MSE가 아니라 Contextual인가
    - ref(T2_moved)는 3mm misalign 상태. L1으로 직접 비교하면
      "위치가 틀어진 것"을 오차로 잘못 벌주게 됨 → blur, 구조 왜곡.
    - Contextual loss는 픽셀 위치 대응을 요구하지 않는다.
      "fake의 각 feature에 대해, ref feature들 중 **가장 비슷한 것**이
       하나라도 있으면 좋다"는 식의 집합 대 집합 유사도.
    - 즉 위치는 자유롭게 두고 **feature 분포(통계)** 를 맞춘다.
      → misalign에 관대하면서 modality 스타일은 전달.

  핵심 아이디어 (Mechrez et al. 2018, "The Contextual Loss")
    - 두 feature 집합 X(fake), Y(ref) 사이에서
      각 x_i 가 가장 가까운 y_j 를 얼마나 확실히 찾는가를 softmax로 계산.
    - 모든 x가 어떤 y와 잘 매칭되면 loss 낮음.

G0. GAN loss가 무엇을 위한 loss인가 (직관)
================================================================================

  목적: fake_b 가 "진짜 T2 영상처럼" 보이도록 = 실제 영상의 sharpness·질감을 갖도록.

  왜 필요한가 (다른 loss와의 역할 분담)
    - Contextual/L1 : 참조와 통계·구조를 맞추지만 결과가 blurry해지기 쉬움.
    - PatchNCE      : 구조(위치 대응) 보존.
    - GAN           : "실제 영상 분포"에 속하도록 밀어 → 고주파 디테일·선명도 회복.
      (앞선 loss ablation에서 GAN을 켜면 sharpness↑, 끄면 SSIM/PSNR↑ 인 트레이드오프
       가 관측된 것이 이 역할을 반영)

  적대 학습 구조 (2-player)
    - Discriminator D : "진짜 T2"와 "합성 fake_b"를 구별하도록 학습.
    - Generator G     : D를 속이도록(=fake를 진짜로 판정하게) 학습.
    - 두 목표가 반대 → 번갈아 최적화 (본 코드는 manual optimization).

      toggle_model()로 해당 파트에만 grad가 흐르도록 격리.


================================================================================
G6. Shape 이동 요약 (GAN, B=1, base)
================================================================================
  fake_b / real_b_disc          [1, 1, 128, 128]
  netD_A(·) 예측 맵             [1, 1, h_d, w_d]   (PatchGAN, 대략 16×16 수준)
  target_label (상수 맵)        [1, 1, h_d, w_d]   (전부 1.0 또는 0.0)
  MSE(pred, target)             스칼라
    loss_gan_b (G측)            = MSE(D(fake_b), 1) × 1
    loss_D_A   (D측)            = 0.5*(MSE(D(real),1) + MSE(D(fake.detach()),0))


================================================================================
G7. base 설정값 (GAN)
================================================================================
  lambda_gan                 1
  gan_type                   lsgan  (→ MSELoss)
  real/fake label            1.0 / 0.0
  loss_weight                1.0 (G에만 곱함, D는 항상 1.0)
  netD_A                     NLayerDiscriminator (PatchGAN)
    input_nc / ndf / n_layers   1 / 64 / 3
    norm / init                 instance / normal
  D real 타깃                real_b_ref 중심 슬라이스 (misalign ref, GT 아님)
  fake 처리                  D 업데이트 시 detach, G 업데이트 시 유지
  업데이트 비율              G:D = 1:1, gradient clip 0.5(norm)


================================================================================
G8. 세 loss 한 줄 대비 (base)
================================================================================
  GAN        : D(fake_b) vs D(ref중심)  — LSGAN(MSE), 실제 분포로 밀어 sharpness↑.
  Contextual : ref 3slice ↔ fake_b      — 위치자유 최근접, 스타일 전달, base는 mean.
  PatchNCE   : T1 ↔ fake_b 같은 위치     — 구조(위치대응) 보존.
  loss_G = GAN(1) + Contextual_mean(5) + PatchNCE(1.5) [+ L1/Perceptual/MIND 옵션]
  loss_D = 0.5*(MSE(D(ref중심),1) + MSE(D(fake),0))   (lambda_gan>0 일 때만)
  공통점: 세 loss 모두 정렬 GT(real_b)를 안 쓰고 misalign ref를 타깃으로 사용.
