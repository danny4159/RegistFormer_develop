1-2. (옵션) apply_linear_registration = True 일 때 벌어지는 일
--------------------------------------------------------------------------------
  base 설정은 False 입니다. True로 켜면 아래가 **데이터셋 생성 시점에 1회**
  (에폭마다가 아니라 __init__에서) 실행되고 결과가 RAM에 캐시됩니다.
  코드: transforms.py:429-473, _register_3d_rigid()는 transforms.py:57-109

  (a) 대상 선정
      registration_targets: [3, 5, 7]  (IXI_Align.yaml 기본값)
      내부 _group_map = {2:'B', 3:'C', 4:'D', 5:'E', 6:'F', 7:'G'}
      → group_3만 정의되어 있으므로 실제 대상은 cache_key 'C' (T2_moved_3mm_RigidReg) 하나.
        group_5, 7은 null이라 자동 스킵.
      → fixed는 항상 data_group_1 (T1).

  (b) 볼륨 전량 로드
      fixed_vols[patient]      = T1 전체 볼륨 (H,W,D)
      raw_moving_vols[patient] = T2_moved 전체 볼륨 (H,W,D)
      ※ 환자 전원의 3D 볼륨을 메모리에 올리므로 RAM 사용량이 큽니다.
        train/val/test 데이터셋이 각각 독립적으로 이 과정을 수행합니다.

  (c) 환자별 3D rigid 정합 — _register_3d_rigid(fixed_np, moving_np, z_pad=20)
      순서대로:
        1) z축 경계 아티팩트 방지용 replicate(edge) padding
           (H,W,D) → (H,W,D+40)   [앞뒤 20슬라이스씩]
        2) numpy (H,W,D) → transpose(2,0,1) → SimpleITK (D,H,W) 로 축 변환
        3) 초기 변환: sitk.CenteredTransformInitializer(
                        fixed, moving, sitk.Euler3DTransform(),
                        CenteredTransformInitializerFilter.GEOMETRY)
           → 두 볼륨의 기하학적 중심을 맞추는 것으로 시작
        4) 정합 최적화: sitk.ImageRegistrationMethod()
             - Metric      : Mattes Mutual Information, numberOfHistogramBins=50
             - Optimizer   : RegularStepGradientDescent
                             learningRate=1.0, minStep=1e-4, numberOfIterations=200
             - OptimizerScalesFromIndexShift()
             - Interpolator: sitkLinear
             - Multi-resolution pyramid:
                 ShrinkFactorsPerLevel   = [4, 2, 1]
                 SmoothingSigmasPerLevel = [2, 1, 0]  (physical units)
        5) 최종 변환으로 resample
             sitk.Resample(moving, fixed, final_tf, sitkLinear,
                           defaultPixelValue=-1.0, moving.GetPixelID())
             → 영상 밖 영역은 배경값 -1.0으로 채움 ([-1,1] 정규화 기준의 "검은색")
        6) SimpleITK (D,H,W) → transpose(1,2,0) → numpy (H,W,D)
        7) z padding 제거: result[:, :, 20 : 20+D_orig]

      변환 모델 정리:
        - Euler3DTransform = 3D rigid, 6-DOF (회전 3 + 평행이동 3)
        - **affine 아님** (scale/shear 없음). 파라미터 이름이 "linear"라서
          affine까지 포함한다고 오해하기 쉬우나 실제 구현은 rigid 단독.
        - ANTs 아님. **SimpleITK** 사용.

  (d) 캐시 저장
      self.reg_cache[patient_key]['C'] = 정합된 T2 볼륨 (H,W,D)
      self._rigid_cached_groups = {'C'}

  (e) non-linear과의 관계 (순차 캐스케이드)
      transforms.py:421 주석 그대로 "Linear(rigid) → NonLinear(ConvexAdam) 순서".
        - linear만 True  : rigid 결과가 최종
        - 둘 다 True     : rigid 결과를 non-linear의 moving 입력으로 넘겨 이어서 정합
                           (_register_3d_nonlinear, method = 'convexadam' | 'anatomix')
        - non-linear만 True: raw 볼륨에서 바로 non-linear 시작
        - 둘 다 False (base): reg_cache 자체를 만들지 않고 h5 원본을 그대로 사용

  (f) __getitem__ 에서의 분기 (transloader 543-549)
      'C' in self._rigid_cached_groups 이면
          vol_C = self.reg_cache[patient_key]['C']    ← h5 대신 캐시에서 읽음
          C = self._load_slice_stack_from_vol(vol_C, slice_idx)
      아니면
          C = self._load_slice_stack(file, data_group_3, patient_key, slice_idx)
      → 이후 경로(스택 구성, crop 등)는 동일.

  (g) base가 False인 이유
      data_group_3이 이미 오프라인에서 rigid 정합까지 끝난 볼륨이라
      True로 켜면 rigid 정합을 이중으로 적용하게 됩니다.

3-2. Q / K 투영 (line 217-223)
--------------------------------------------------------------------------------
  Q (T1 쪽) — K축 없음:
      q = self.q_proj(src_low)
      q_proj = nn.Conv2d(1, dim=16, kernel_size=1)     [base: qk_conv3=False]
      [B,1,16,16] → q [B, 16, 16, 16]                  (B, dim, h, w)

  K (T2 쪽) — K축을 배치로 접었다 펴는 트릭:
      k = self.k_proj(ref_base.reshape(B*K, 1, h, w)).view(B, K, dim, h, w)
      1) reshape : [B,3,16,16] → [B*3, 1, 16, 16]      (슬라이스 3장을 배치로)
      2) k_proj  : nn.Conv2d(1, 16, 1) 적용 → [B*3, 16, 16, 16]
      3) view    : → k [B, 3, 16, 16, 16]              (B, K, dim, h, w)

      ★ 슬라이스별로 독립 conv (가중치는 공유). in_channels=1 이므로
        이 단계에서 슬라이스 간 정보 교환은 전혀 없음.
        슬라이스 간 상호작용은 오직 뒤의 softmax에서만 발생.

  QK 정규화 — base는 use_qk_norm=True (line 221-223)
      q = F.normalize(q, dim=1)   ← 채널축 기준 L2 정규화 (위치마다 단위벡터)

      → 내적이 곧 코사인 유사도가 되어 Q,K가 0으로 붕괴하는 것을 방지.
      → 대신 스케일이 [-1,1]로 눌리므로 학습 가능한 temperature로 증폭:
          self.log_temperature = nn.Parameter(log(init_temperature=10.0))

  V: base는 use_direct_attn=True 이므로 **v_proj / out_proj 자체를 만들지 않음**
     (line 178-185: not use_direct_attn 일 때만 생성)

3-5. Value 집계 — direct 모드 (line 279-287)
--------------------------------------------------------------------------------
  attn_mean = attn_for_log.mean(dim=1)    → [B, 3, 9, 16, 16]  (head 평균, base는 head 1개)

4-2. StyleConv 내부 연산 순서 (line 857-989)
--------------------------------------------------------------------------------
  입력: x [B, C_in, H_x, W_x],  style [B, 1, 16, 16]

  (1) 공간 변환
      downsample=True : x = self.down(x)
                        down = Conv2d(C_in, C_f, kernel_size=1, stride=2, padding=0)
                        → 해상도 1/2
      upsample=True   : x = self.up(x)
                        up = Sequential(Upsample(scale_factor=2, mode='nearest'),
                                        Conv2d(C_in, C_f, 3, padding=1))
                        → 해상도 2배
      둘 다 False     : x = self.conv(x)
                        conv = Conv2d(C_in, C_f, 3, padding=1)
      (Blur 모듈은 생성되지만 forward에서 호출되지 않음 — 역시 데드코드)

  (2) 정규화
      x = self.normalize(x)
      normalize = nn.InstanceNorm2d(C_f, affine=False)
      → 채널별로 공간 평균/분산 제거. affine=False이므로 학습 파라미터 없음.
        여기서 "원본 x의 통계(스타일)"를 지우고, 아래 (4)에서 ref 기반 통계로 재주입.

  (3) 노이즈 주입 (StyleGAN 방식)
      noise = torch.randn_like(x) * self.noise_strength
      x = x + noise
      noise_strength: nn.Parameter(zeros(1)) — 0에서 시작해 학습으로 조절
      base는 noise_independent=False (단일 noise_strength)

  (4) style → modulation 파라미터 추정  ★핵심
      a) 해상도 정합
         style = F.interpolate(style, size=x.size()[2:], mode='nearest')
         [B,1,16,16] → 해당 레이어 해상도로 확대 (128 / 64 / 32 각각)
         ※ nearest 보간이라 style map은 블록 형태로 확대됨
           (DS=8이면 원본 기준 8×8 픽셀이 하나의 style 값을 공유)

      b) MLP (실제로는 3×3 conv, spatial-aware SPADE 계열)
         mlp_shared = Sequential(Conv2d(1, 512, 3, padding=1), ReLU())
         actv  = mlp_shared(style)          → [B, 512, H_x, W_x]
         gamma = mlp_gamma(actv)            Conv2d(512, 264, 3, padding=1) → [B,264,H_x,W_x]
         beta  = mlp_beta(actv)             Conv2d(512, 264, 3, padding=1) → [B,264,H_x,W_x]

         ★ gamma/beta가 스칼라가 아니라 **픽셀마다 다른 spatial map**.
           즉 위치별로 다른 정규화 통계를 주입 (AdaIN이 아니라 SPADE 형태).

      c) affine modulation
         x_pre = x
         x = x * gamma + beta

  (5) 활성화
      x = LeakyReLU(negative_slope=0.2)(x)     [activate=True인 모든 레이어]

  → 13개 StyleConv 전부에 **동일한 style_guidance_1**이 들어감.
    레이어마다 mlp_shared/mlp_gamma/mlp_beta는 별도 파라미터이므로,
    같은 style map에서 레이어별로 다른 modulation을 학습.

  style modulation 진단 로그 (log_style_modulation=true, line 971-984):
    gamma_abs, beta_abs                 modulation 크기
    gamma_spatial_std, beta_spatial_std 위치별 변동 (0에 가까우면 AdaIN처럼 동작 중)
    delta_ratio                         |x - x_pre| / |x_pre| — modulation 영향력
    x_out_over_x_pre                    출력/입력 크기 비
    style_in_std, style_in_spatial_std  들어온 style map의 분산

================================================================================
10. 설계 의도 요약
================================================================================

  1) 왜 attention인가
     T2가 3mm misalign된 상태이므로 중심 슬라이스를 그대로 style로 쓰면
     잘못된 위치의 조직 대비가 주입됩니다. K=3 슬라이스 × 3×3 이웃 = 27개 후보에서
     T1 query와 가장 유사한 지점을 골라 style을 구성해 misalignment를 흡수합니다.

  2) 왜 DS=8로 다운샘플하는가
     style은 "어디에 무엇이 있는가"가 아니라 "어떤 대비/텍스처인가"를 전달하는 역할.
     저해상도로 낮춰 구조적 세부(=misalign에 취약한 정보)를 의도적으로 버리고
     조직 대비 정보만 남깁니다. 구조는 T1(x)에서 skip connection으로 전달.

  3) 왜 direct + alpha=1.0인가
     V 투영과 out_proj를 거치면 네트워크가 style을 임의로 만들어낼 수 있어
     "참조 영상에서 왔다"는 보장이 약해집니다. direct는 attention 가중치로
     raw T2 픽셀값만 섞으므로 style이 반드시 실제 T2 값의 볼록결합이 됩니다.

  4) 왜 qk_norm + temperature인가
     정규화 없이 학습하면 Q,K가 0으로 수렴해 attention이 균등분포로 붕괴하는
     현상이 있었습니다(진단 지표 qk_score_std_nobias). 코사인 유사도로 크기를 고정하고
     학습 가능한 temperature로 변별력을 확보합니다.

  5) 왜 GT(real_b)를 loss에 안 쓰는가
     실제 임상에서는 완벽히 정렬된 타깃이 없다는 가정. misalign된 참조만으로
     학습하고, 평가만 GT로 하여 방법의 실효성을 검증하는 설계입니다.
