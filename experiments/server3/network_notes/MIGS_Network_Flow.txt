── 2-0. training_step 진입 ────────────────────────────────────────────────
  src/models/proposed_synthesis_module.py : MIGSModule.training_step()
    automatic_optimization=False (수동 최적화)
    use_gan = (lambda_gan>0) = True →
        optimizer_G_A, optimizer_D_A, optimizer_F_A = self.optimizers()

        └ 여기서 Generator forward 1회 실행 = fake_b(synthesized_slice) 생성

── 2-1. model_step → forward (fake_b 생성) ────────────────────────────────
  src/models/base_module_AtoB.py : model_step()  (use_25d 분기)
      real_a, real_b, real_b_ref = batch
      fake_b = self.forward(real_a, real_b_ref)

  src/models/base_module_AtoB.py : forward()
      type(netG_A).__name__ == "ProposedSynthesisModule" (=MIGSGenerator alias) →
      merged_input = torch.cat((real_a, real_b_ref), dim=1)   # [B,4,128,128]
                                                                ch0=fixed(T1), ch1..3=moving stack(T2_moved)
      is_3d=False, use_sliding_inference=False (base) →
      return self.netG_A(merged_input)

── 2-2. Generator forward (network_proposed_synthesis.MIGSGenerator.forward) ──

  [2-2-0] 입력 분리
      fixed_slice   = merged_input[:, :1]     # [B,1,128,128]  T1 (query)
      moving_inputs = merged_input[:, 1:]     # [B,3,128,128]  T2_moved stack (key/value)
      is_3d=False → else 분기로 진입

  [2-2-1] CGM(Contrast Guidance Map) 생성 → _build_contrast_guidance(fixed_slice, moving_inputs)
      _get_cgm_size(fixed_slice): h,w = 128//8 = 16,16   (swa_downsampling_factor=8)
      _use_ref_conditioner = not(multi/triple output) = True (base는 단일 출력)
      guidance_mode='swa' (conv_ablation 아님) →
      use_25d_style=True, ref_stack_size=3>=1 →
          moving_stack = _select_moving_stack(moving_inputs) = moving_inputs[:, :3]   # [B,3,128,128]
          cgm, stats = self.ref_conditioner_25d(fixed_slice, moving_stack, (16,16))

      ┌── SliceWindowAttention.forward — SWA 블록 ──────────────────────────────┐
      │ (a) 다운샘플 (bilinear 고정)                                             │
      │     fixed_slice_down  = interpolate(fixed_slice,  (16,16), bilinear) # [B,1,16,16]│
      │     moving_stack_down = interpolate(moving_stack,(16,16), bilinear) # [B,3,16,16]│
      │     moving_base = moving_stack_down   (coarse pooling 없음, full-res 고정)      │
      │ (b) Q/K 투영 (1x1 conv 고정)                                            │
      │     query = q_proj(fixed_slice_down)                  # [B,16,16,16]     │
      │     keys  = k_proj(moving_base.reshape(B*3,1,16,16)).view # [B,3,16,16,16] │
      │     use_cosine_similarity=true → query=L2norm(dim=1), keys=L2norm(dim=2) │
      │ (c) 로컬윈도우 unfold (win=3)                                           │
      │     local_keys                                        # [B,3,16,9,16,16]│
      │ (d) logits = (query·local_keys) * temperature(=exp(log_temperature))    │
      │            # [B,3,9,16,16]                                              │
      │     center_slice_bias(=0.0, 가산되나 무효과) → center 슬라이스 로짓에 가산│
      │     attention_weights = softmax over K*win2(=27)      # [B,3,9,16,16]    │
      │     (swa_use_uniform_attention=false → 이 attn 그대로 사용)              │
      │ (e) direct 집계 (v_proj/out_proj 없음, swa_use_raw_values=true)          │
      │     moving_value_candidates = unfold(moving_base)     # [B,3,9,16,16]    │
      │     weighted_moving = Σ(attn_mean*moving_value_candidates) # [B,1,16,16] │
      │     center_moving = moving_stack_down[:,1:2] ; cgm_blend_alpha=1.0       │
      │     cgm = center_moving + 1.0*(weighted_moving-center_moving)           │
      │        = weighted_moving                                                │
      │ (f) 통계 stats + last_attn_entropy(미분가능, entropy reg용) 저장         │
      │     return cgm [B,1,16,16], stats                                       │
      └───────────────────────────────────────────────────────────────────────┘
      → cgm = [B,1,16,16]

  [2-2-2] MIGConv U-Net 본체 (cgm을 전 레이어에 동일 주입, 12블록)
      stem_feat = conv0 (fixed_slice,         cgm)   1→264  , 128x128
      enc1_feat = conv11(stem_feat,           cgm)   264→264, 128→64    [downsample]
      enc1_feat = conv12(enc1_feat,           cgm)   264→264, 64x64
      enc2_feat = conv21(enc1_feat,           cgm)   264→264, 64→32     [downsample]
      enc2_feat = conv22(enc2_feat,           cgm)   264→264, 32x32
      bottleneck_feat = conv31(enc2_feat,     cgm)   264→264, 32x32
      bottleneck_feat = conv32(bottleneck_feat,cgm)  264→264, 32x32
      dec1_feat = conv41(bottleneck_feat+enc2_feat, cgm) 264→264, 32→64 [upsample, skip+]
      dec1_feat = conv42(dec1_feat,           cgm)   264→264, 64x64
      dec2_feat = conv51(dec1_feat+enc1_feat, cgm)   264→264, 64→128    [upsample, skip+]
      dec2_feat = conv52(dec2_feat,           cgm)   264→264, 128x128
      refined_feat = conv6(dec2_feat+stem_feat, cgm) 264→264, 128x128  [skip+]
      use_separate_style_layers=false, 단일출력 → else 분기:
          out            = conv_final(refined_feat)  264→1  , 128x128   [Conv2d 3x3]
          synthesized_slice(=fake_b) = tanh(out)      # [B,1,128,128]  in [-1,1]

      ┌── MIGConv.forward(feature, cgm) 내부 — 1개 블록 구조 ──────────────────┐
      │ (1) 공간변환: downsample→down(Conv k1,s2) / upsample→up(Upsample+Conv3)│
      │              / else→conv(Conv 3x3)                                    │
      │ (2) 정규화: x = InstanceNorm2d(264, affine=False)(x)                   │
      │ (3) 노이즈: x = x + randn_like(x)*noise_strength                       │
      │ (4) cgm→변조 파라미터 (SPADE형):                                       │
      │     style = interpolate(cgm, x크기, mode='nearest')                    │
      │     cgm_features = mlp_shared(style)  Conv2d(1,512,3)+ReLU  #[B,512,.,.]│
      │     gamma = mlp_gamma(cgm_features)   Conv2d(512,264,3)     #[B,264,.,.]│
      │     beta  = mlp_beta(cgm_features)    Conv2d(512,264,3)     #[B,264,.,.]│
      │     x = gamma*x + beta            ← 픽셀별 affine 변조 (CGM-derived)    │
      │ (5) 활성: x = LeakyReLU(0.2)(x)                                        │
      └─────────────────────────────────────────────────────────────────────┘
      ※ mlp_shared/gamma/beta는 MIGConv 12개가 각각 별도 파라미터

── 2-3. compute_generator_loss (Generator loss) ───────────────────────────
  src/models/proposed_synthesis_module.py : MIGSModule.training_step() 내
  with optimizer_G_A.toggle_model():   (G/F에만 grad)
    moving_ref_b = real_b_ref  (use_25d)   ← 모든 loss 타깃은 moving stack (GT 아님)

    [L1] GAN loss:
        pred_fake = netD_A(fake_b)              # PatchGAN [B,1,~16,~16]
        loss_gan_b = criterionGAN(pred_fake,True)*lambda_gan(1) = MSE(D(fake),1)
    [L2] Contextual(cx) loss (_compute_cx_loss_over_moving_stack):
        VGG19 6층 특징, moving stack 3장 각각 vs fake_b → cx_0,1,2
        cx_stack_aggregation='mean' → mean(cx)*lambda_cx(5)
    [L3] PatchNCE loss (단일출력, encode_only=True 재사용):
        dummy_moving_stack = real_a.repeat(1,3,1,1)
        synthesized_features = netG_A(cat(fake_b,dummy_moving_stack), nce_layers=[0,2,4,6], encode_only=True)
        fixed_features       = netG_A(cat(real_a,moving_ref_b), nce_layers,          encode_only=True)
            └ encode_only=True → forward가 synthesized_slice 대신
              [stem_feat,enc1_feat,enc2_feat,refined_feat] 반환
              (netG_A forward 2회 추가 = 스텝당 Generator forward 총 3회)
        netF_A(PatchSampleF): 층별 256위치 샘플→MLP(264→256)→L2norm  # [256,256]
        PatchNCELoss(nce_T=0.07): InfoNCE(같은위치 positive, 나머지 negative)
        loss_nce_b = Σ_layer mean(NCE)*lambda_nce(1.5) / 4
    [L4] SWA entropy 규제: lambda_swa_entropy=0(base) → 스킵 (no-op)
    loss_G = gan(1) + cx_mean(5) + nce(1.5)
    manual_backward(loss_G); clip_grad(G,0.5); clip_grad(F,0.5)
    optimizer_G_A.step(); optimizer_F_A.step(); zero_grad

── 2-4. Discriminator loss (backward_D_A, base_module_AtoB.py 공용) ────────
  moving_center_for_discriminator = real_b_ref[:,1:2]  (moving stack 중심 슬라이스)
      ← _select_discriminator_real_slice(): use_25d=True, K=3>1 → 중심 슬라이스 선택
  with optimizer_D_A.toggle_model():
    src/models/base_module_AtoB.py : backward_D_A() → backward_D_basic()
        loss_D_A = 0.5*( MSE(netD_A(moving_center_for_discriminator),1)
                        + MSE(netD_A(fake_b.detach()),0) )
    manual_backward; clip_grad(D,0.5); optimizer_D_A.step(); zero_grad

  netD_A 구조 (NLayerDiscriminator, PatchGAN, networks_define.py):
    Conv(1→64,k4,s1,p1)+LReLU+Downsample
    Conv(64→128)+InstanceNorm+LReLU+Downsample
    Conv(128→256)+InstanceNorm+LReLU+Downsample
    Conv(256→512)+InstanceNorm+LReLU
    Conv(512→1,k4,s1,p1)               # 예측맵 [B,1,~16,~16]

── 2-5. optimizer / scheduler ─────────────────────────────────────────────
    Adam(lr=1e-4, betas=[0.5,0.999], wd=1e-4)  × (G_A, D_A, F_A)
    scheduler = MultiStepLR([250000,300000], gamma=0.5)
    Trainer: max_epochs=100, precision=32, strategy=ddp, grad_clip 0.5(norm)

PART 5. 블록 진행 순서 요약 (한 줄 흐름)
################################################################################

TRAIN:
  DataLoader → merged_input(cat)
  → training_step → model_step → BaseModule.forward
  → netG_A.forward (MIGSGenerator):
       _build_contrast_guidance → SliceWindowAttention.forward
         [bilinear down → q_proj/k_proj(1x1) → cosine → unfold(win3)
          → softmax(27) → direct weighted_moving] → cgm[1,1,16,16]
       → conv0..conv6 (MIGConv×12; 각: down/up/conv → InstanceNorm → +noise
          → CGM 변조(mlp_shared/gamma/beta 3x3) → LeakyReLU)
       → conv_final(3x3) → tanh → fake_b
  → compute_generator_loss [GAN(netD_A) + Contextual/cx(VGG19) + PatchNCE(netG_A
       encode_only ×2 + netF_A + InfoNCE)] → step(G,F)
  → backward_D_A [netD_A: 0.5(MSE(moving stack 중심,1)+MSE(fake,0))] → step(D)

INFERENCE:
  DataLoader → model_step → BaseModule.forward → netG_A.forward
  (SWA → MIGConv×12 → conv_final → tanh) → fake_b
  → test_step metric update (SSIM/PSNR/LPIPS/Sharpness vs real_b GT)
